1 What are operators?

An operator is a symbol that tells the computer to perform a specific mathematical, relational, or logical operation on one or more values (called operands). Think of operators as the "verbs" of programming — they do things to the data.

💡 Key idea: In the expression 5 + 3, the numbers 5 and 3 are the operands, and the + sign is the operator. The operator tells the computer to add the two numbers together.

Operators are grouped into several categories based on what they do. In this lesson, we will cover the four most important categories:

  • Arithmetic operators — perform mathematical calculations
  • Assignment operators — assign values to variables
  • Comparison operators — compare two values
  • Logical operators — combine multiple conditions

2 Arithmetic Operators

Arithmetic operators are used to perform basic mathematical operations. They are the most familiar type of operator because they work just like the math you already know.

Operator Name Example Result
+ Addition 10 + 3 13
− Subtraction 10 − 3 7
* Multiplication 10 * 3 30
/ Division 10 / 3 3.333…
% Modulus (remainder) 10 % 3 1
** Exponent (power) 2 ** 3 8

Example in code

# Arithmetic operators in action
a = 10
b = 3

print(a + b)   # 13 (addition)
print(a - b)   # 7 (subtraction)
print(a * b)   # 30 (multiplication)
print(a / b)   # 3.33 (division)
print(a % b)   # 1 (remainder)
print(a ** b) # 1000 (power)

💡 The modulus operator (%) is especially useful. It returns the remainder after division. For example, 10 % 3 equals 1 because 3 goes into 10 three times (9) with 1 left over.

Common use: Checking if a number is even or odd — if n % 2 == 0, the number is even.

3 Assignment Operators

Assignment operators are used to assign values to variables. The most basic assignment operator is the single equals sign (=), which stores the value on the right into the variable on the left.

⚠️ Important: In programming, = does not mean "equals" in the mathematical sense. It means "assign the value on the right to the variable on the left." For comparison, we use == (see the next section).
Operator Name Example Equivalent to
= Assign x = 5 x = 5
+= Add and assign x += 3 x = x + 3
−= Subtract and assign x −= 3 x = x − 3
*= Multiply and assign x *= 3 x = x * 3
/= Divide and assign x /= 3 x = x / 3
%= Modulus and assign x %= 3 x = x % 3

Example in code

# Assignment operators in action
score = 100       # assign 100 to score
score += 50      # score is now 150
score -= 30      # score is now 120
score *= 2       # score is now 240
score /= 4       # score is now 60

print(score)   # 60

The shorthand operators (+=, −=, etc.) are simply a convenient way to update a variable based on its current value. They save you from writing the variable name twice.

4 Comparison Operators

Comparison operators are used to compare two values. They always return a Boolean result: either true or false. These are essential for making decisions in your code (e.g., in if statements).

Operator Name Example Result
== Equal to 5 == 5 true
!= Not equal to 5 != 3 true
> Greater than 5 > 3 true
< Less than 5 < 3 false
>= Greater than or equal 5 >= 5 true
<= Less than or equal 3 <= 5 true

Example in code

# Comparison operators return True or False
x = 10
y = 20

print(x == y)   # False
print(x != y)   # True
print(x < y)    # True
print(x > y)    # False
print(x <= 10) # True
print(y >= 25) # False

⚠️ Watch out: = is assignment, while == is comparison. Mixing them up is one of the most common beginner mistakes!

x = 5 → puts 5 into x.
x == 5 → asks "is x equal to 5?"

5 Logical Operators

Logical operators are used to combine multiple conditions. They are the glue that lets you build complex decision-making into your programs. Like comparison operators, they return true or false.

Operator Name Description Example
&& AND True only if both conditions are true (5 > 3) && (2 < 4) → true
|| OR True if at least one condition is true (5 > 3) || (2 > 4) → true
! NOT Reverses the result (true → false, false → true) !(5 > 3) → false

Example in code

# Logical operators in action
age = 25
has_license = True

# AND: both must be true
can_drive = (age >= 18) && has_license
print(can_drive)   # True

# OR: at least one must be true
is_weekend = True
is_holiday = False
can_relax = is_weekend || is_holiday
print(can_relax)   # True

# NOT: reverses the value
is_raining = False
print(!is_raining) # True

💡 Practical example: A website login might check:

if (username == "admin" && password == "1234") { ... }

Both conditions must be true for the login to succeed. If you used || instead, the login would succeed if either the username or password matched — which would be a security disaster!

6 Operator Precedence

When an expression contains multiple operators, the computer needs to know which one to evaluate first. This is called operator precedence. It works much like PEMDAS in mathematics.

Order of precedence (highest to lowest):

1. Parentheses ( )

2. Exponent **

3. Multiplication, Division, Modulus * / %

4. Addition, Subtraction + −

5. Comparison == != > < >= <=

6. Logical NOT !

7. Logical AND &&

8. Logical OR ||

9. Assignment = += −= etc.

# Precedence example
result = 2 + 3 * 4
# Multiplication first: 3 * 4 = 12
# Then addition: 2 + 12 = 14
print(result)   # 14

# Use parentheses to change the order
result2 = (2 + 3) * 4
print(result2) # 20

Best practice: When in doubt, use parentheses. They make your code clearer and prevent unexpected results.

7 Key facts to remember

• Arithmetic operators: + − * / % ** → do math.

• Assignment operators: = += −= *= /= %= → store and update values.

• Comparison operators: == != > < >= <= → return true or false.

• Logical operators: && || ! → combine conditions.

• = is assignment, == is comparison — don't confuse them!

• % returns the remainder of division (e.g., 10 % 3 = 1).

• && requires both conditions to be true.

• || requires at least one condition to be true.

• ! reverses a Boolean value.

• Use parentheses to control the order of evaluation.
