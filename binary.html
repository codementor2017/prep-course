1 What is the binary system?

The binary system is a base‑2 number system. Unlike the decimal system (base‑10) that we use every day — which relies on ten digits (0–9) — binary uses only two digits: 0 and 1.

Each digit in a binary number is called a bit (short for binary digit). The binary system is the foundation of all modern computers and digital electronics, because a bit can be easily represented by two physical states: on/off, high/low voltage, or magnetized/ demagnetized.

💡 Key idea: In binary, every position represents a power of 2. That's why it is called a positional or place‑value system — the value of a digit depends on its position within the number.

2 Place values — powers of 2

In the decimal system, each position is a power of 10: ones, tens, hundreds, thousands, etc. In binary, each position is a power of 2. Starting from the right (least significant bit), the place values are:

4

2

So a 4‑bit binary number has place values 8, 4, 2, and 1. For example, the binary number 1011 means:

1 0 1 1
8 4 2 1
(1×8) + (0×4) + (1×2) + (1×1) = 8 + 0 + 2 + 1 = 11

3 Counting in binary

Counting in binary works exactly like counting in decimal, but you run out of digits much faster. After 1, you cannot go to 2 — you must roll over to the next position. Here is how you count from 0 to 15 using 4 bits:

Notice the pattern: the least significant bit (rightmost) alternates 0, 1, 0, 1…; the next bit alternates every two numbers, then every four, then every eight — each bit toggles at twice the rate of the one to its left. This is a direct consequence of the powers‑of‑2 place values.

4 Converting binary → decimal

To convert a binary number to decimal, multiply each bit by its place value (power of 2) and add the results. Let's walk through a 6‑bit example:

1 0 1 1 0 1
32 16 8 4 2 1
(1×32) + (0×16) + (1×8) + (1×4) + (0×2) + (1×1) = 32 + 0 + 8 + 4 + 0 + 1 = 45

So 101101₂ = 45₁₀. The subscript ₂ indicates binary, and ₁₀ indicates decimal.

5 Converting decimal → binary

There are two common methods. The most reliable is repeated division by 2:

  1. 1. Divide the decimal number by 2.
  2. 2. Record the remainder (0 or 1).
  3. 3. Divide the quotient by 2 again.
  4. 4. Repeat until the quotient is 0.
  5. 5. Read the remainders from bottom to top.

Let's convert decimal 26 to binary:

26 ÷ 2 = 13   remainder 0   ← least significant
13 ÷ 2 = 6    remainder 1
6  ÷ 2 = 3    remainder 0
3  ÷ 2 = 1    remainder 1
1  ÷ 2 = 0    remainder 1   ← most significant

Reading the remainders from bottom to top: 1 1 0 1 0. So 26₁₀ = 11010₂.

6 🌍 Real‑world application: ASCII

So far we've used binary to represent numbers. But how does a computer store text — letters, symbols, emojis? The answer is ASCII (American Standard Code for Information Interchange).

ASCII assigns a unique number (and therefore a unique binary pattern) to every character: letters A–Z, a–z, digits 0–9, punctuation, and control codes. Each character is stored using 7 or 8 bits (a byte).

🔤 ASCII in action

Every character you type is stored as a binary number. Here are a few examples:

A → decimal 65 → 01000001
B → decimal 66 → 01000010
a → decimal 97 → 01100001
! → decimal 33 → 00100001

Let's decode the word "Hi" using ASCII:

H = 72 = 0 1 0 0 1 0 0 0
i = 105 = 0 1 1 0 1 0 0 1

When you type "Hi" on a keyboard, the computer stores these two 8‑bit binary patterns. When you open a text file, the computer reads the binary and converts it back to characters using the ASCII table.

Why this matters: Every photo, video, song, website, and message on your phone is ultimately stored as billions of 0s and 1s. Binary is the language of the digital world — and ASCII is how we map human-readable characters onto that language.

7 Key facts to remember

• 1 bit → 2 possible values (0, 1)

• 2 bits → 4 values (00, 01, 10, 11)

• 3 bits → 8 values (000 – 111)

• n bits → 2n unique combinations

• Byte = 8 bits → 256 possible values (0–255)

• The rightmost bit is the least significant bit (LSB) and has place value 1.

• The leftmost bit is the most significant bit (MSB) — its place value grows as 2n‑1.

• ASCII maps characters to numbers (e.g., 'A' = 65 = 01000001).

• Binary 1010 = decimal 10

• Binary 11111111 = decimal 255
