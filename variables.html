1 What is a variable?

A variable is a named container that stores a value in a computer's memory. Think of it like a labeled box: the label is the variable's name, and the contents of the box are the variable's value.

Variables allow programs to remember information, change it over time, and reuse it throughout the code. Without variables, every value would have to be hard-coded and could never change — making programs rigid and nearly useless.

💡 Key idea: A variable is a named reference to a value stored in memory. When you write age = 25, you are telling the computer: "Create a box labeled age and put the value 25 inside it."

2 How to write a variable

In most programming languages, creating a variable involves three steps: declaration, assignment, and usage. The exact syntax depends on the language, but the concept is universal.

Step 1 — Declaration & Assignment

You declare a variable by giving it a name, and you assign a value to it using the equals sign (=). In many languages, this happens in a single line:

# Python — no keyword needed
age = 25
name = "Alice"
is_student = True

// JavaScript — uses let or const
let age = 25;
const name = "Alice";

// Java — requires a type
int age = 25;
String name = "Alice";

Step 2 — Using the variable

Once a variable is created, you can use its name anywhere you want its value. The computer will substitute the stored value automatically:

age = 25
print(age)        # 25
print(age + 5)   # 30
print("I am", age) # I am 25

Step 3 — Reassigning (changing the value)

Unlike mathematics, a variable's value can change during the program. This is one of the most important differences between variables in programming and variables in math.

score = 0
print(score)   # 0

score = 10   # reassign a new value
print(score)   # 10

score += 5   # increase by 5
print(score)   # 15

3 How should variables be named?

Choosing good variable names is one of the most important skills in programming. A well-named variable makes code self-documenting — anyone reading it can understand what it does without extra comments.

Syntax rules (must follow)

  • Names must start with a letter or an underscore (_), not a digit.
  • Names can contain letters, digits, and underscores — no spaces or special symbols.
  • Names are case-sensitive: age, Age, and AGE are three different variables.
  • You cannot use reserved keywords (like if, while, class, return).

Style conventions (should follow)

Convention Style Example
snake_case lowercase words separated by underscores user_name, total_price
camelCase first word lowercase, following words capitalized userName, totalPrice
PascalCase every word capitalized (usually for classes) UserName, TotalPrice
SCREAMING_SNAKE uppercase with underscores (for constants) MAX_SIZE, PI

Good vs. bad names

✅ Good

user_age — clear and descriptive

total_price — tells you what it holds

is_logged_in — reads like a true/false question

MAX_SPEED — constant, uppercase

❌ Bad

a — meaningless

x1 — unclear

data — too vague

TotalPriceIncludingTax — overly long

user name — contains a space (invalid)

4 How variables differ from mathematics

If you have studied algebra, you already know about variables like x and y. But programming variables behave quite differently from mathematical variables. This is one of the most important conceptual shifts for beginners.

Aspect Mathematics Programming
Meaning A variable represents an unknown value to be solved A variable is a named container for a stored value
Can it change? Usually fixed — x stays the same within a problem Yes — the value can be reassigned at any time
Naming Short symbols like x, y, n Descriptive names like user_age, total_score
Equation meaning x = x + 1 is unsolvable (or means "no solution") x = x + 1 means "increase x by 1" — perfectly valid!
Case sensitivity X and x often considered the same X and x are two different variables
Purpose To solve for an unknown To store, retrieve, and manipulate data

⚠️ The biggest mental shift: In math, x = x + 1 is a contradiction (no number equals itself plus one). In programming, it is a perfectly normal instruction: "take the current value of x, add 1, and store the result back into x."

This is called reassignment, and it is one of the most powerful features of programming variables.

Example: math vs. programming

# In programming, this is completely valid:
counter = 0
counter = counter + 1   # counter is now 1
counter = counter + 1   # counter is now 2
counter = counter + 1   # counter is now 3
print(counter)       # 3

This pattern of repeatedly updating a variable is the foundation of loops, counters, accumulators, and countless other programming techniques.

5 What can variables hold?

Variables can store many kinds of values — not just numbers. The kind of value a variable holds is called its data type. Here are the most common ones:

Type Description Example
Integer Whole numbers (positive, negative, or zero) age = 25
Float Decimal numbers price = 19.99
String Text — letters, words, sentences name = "Alice"
Boolean True or false values is_active = True
List / Array An ordered collection of values scores = [90, 85, 77]

Some languages (like Python and JavaScript) allow a variable to change its type dynamically. Others (like Java and C++) require you to declare the type upfront, and it cannot change.

# Python: type can change dynamically
x = 42         # integer
x = "hello"   # now a string — that's fine

// Java: type is fixed at declaration
int x = 42;
// x = "hello"; // ERROR — x must stay an int

6 Best practices for using variables

  • Use meaningful names — total_price is far better than tp.
  • Be consistent — pick one naming style (snake_case or camelCase) and stick with it.
  • Avoid single letters — except for simple loop counters like i, j.
  • Keep names readable — avoid abbreviations that aren't obvious.
  • Use constants for fixed values — MAX_SIZE = 100 in uppercase.
  • Declare variables close to where they're used — improves readability.
  • Don't reuse variables for different purposes — it confuses readers and can cause bugs.
  • Comment when necessary — explain why, not what.

7 Key facts to remember

• A variable is a named container for a value in memory.

• Creating a variable = declaring its name + assigning a value.

• Variables can be reassigned — their value can change during the program.

• x = x + 1 is valid in programming (means "increase x by 1").

• Names must start with a letter or underscore, and cannot contain spaces.

• Names are case-sensitive: age ≠ Age.

• Use snake_case or camelCase for readability.

• Constants (unchanging values) use SCREAMING_SNAKE_CASE.

• Variables can hold many types: integers, floats, strings, booleans, lists.

• Unlike math, a programming variable is a storage box, not an unknown.
